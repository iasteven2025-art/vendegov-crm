VendeGov CRM - sistema local

Abra index.html para acessar o sistema. Esta versao esta preparada para Firebase e GitHub. Enquanto o arquivo firebase-config.js nao estiver preenchido, ela funciona em modo local.

O que esta incluido

Painel executivo, agenda e viagens, clientes, licitacoes, propostas, marketing, contratos, entrega de documentos, renovacoes, comissoes, relatorios de vendas, relatorios gerenciais, relatorios de comissoes, empresas, regioes, documentos importantes, parametros do sistema, usuarios, grupos de usuarios, templates de e-mail e log de auditoria.

Onde os dados ficam salvos

Com Firebase configurado, os dados ficam no Cloud Firestore e os anexos no Cloud Storage. Sem Firebase, os dados ficam no navegador, usando armazenamento local.

Proxima etapa para virar SaaS real

Siga o arquivo README-DEPLOY-FIREBASE-GITHUB.md para criar o projeto Firebase, conectar o GitHub e publicar o sistema.
